# 同一句抹茶口播，三种读法

点开 [7 秒试听](./same-line.mp3)，三次说的都是「这一杯，先别搅。」。第一遍是上一版使用的 macOS Tingting，第二遍是 Qwen3-TTS 的 Vivian 温暖口吻，第三遍是同一个 Vivian 的轻快口吻。第二、三遍使用同一份定稿、同一预置音色和随机种子，改变给配音模型的朗读指令。试听使用独立人声，按相同响度目标调整增益，两遍之间留 0.7 秒。

| 读法 | 15 秒完整人声 | 这次能控制什么 |
| --- | --- | --- |
| macOS Tingting | [系统朗读](./tingting.mp3) | 旧样片的调用只传入文字和系统音色 |
| Kokoro 59 | [本地 CPU 音色](./kokoro.mp3) | 神经音色、台词标点与镜头停顿 |
| Vivian 温暖口吻 | [温暖版](./vivian-warm.mp3) | 像店主近距离说给一位客人听，句尾轻收 |
| Vivian 轻快口吻 | [轻快版](./vivian-bright.mp3) | 带一点惊喜，动词更突出，问句上扬 |

**机械感需要从两个入口处理。** 写稿时，把商品名和卖点写成能对人说的一句话。合成时，把语气作为单独的模型输入，分别说明开场如何提醒、中段如何指给顾客看、片尾如何邀请。这样导演指令不会被念出来，确认的商品名称、价格、限制条件仍按原文保留。配乐在发声时压低约 11 dB，字幕以测得的发声区间进入和退出。[配音实现](../../../../../server/film_voice.py) · [Qwen 语气控制](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice)

在本机，温暖和轻快两个开场实读分别约 1.79 秒和 2.03 秒。两条完整样音都能在三镜内读完，速度和音高分布有可测差别。Whisper 回读识别出了开场和「抹茶和牛奶」，“杯壁”“到店”等词出现过近音转写。听感与清晰度可直接用同稿试听判断。[温暖版成片](../expressive/film.mp4) · [成片字幕](../expressive/captions.srt)
