# 抹茶拿铁的周五改价与片尾试听

**两段试听使用同一句新价台词「周五到店，19.90元。」。** 用同一个 Vivian 音色读出「星期五，到店十九块九」。温和版停顿较长，轻快版收尾更快。最终交付使用下载到的轻快版录音。[温和读法](warm.wav) · [轻快读法](bright.wav)

**片尾从第 10 秒开始。** 前两镜仍说「这一杯，先别搅。」「你看，抹茶和牛奶分了层。」。两条最终 MP4 解码后的前 240 帧逐帧相同，前 10 秒人声和配乐各自逐采样相同。两版剪辑包中，整条无字商品画面的 SHA-256 一致。修改版只更新片尾读法、价格字样和对应字幕时码。选中的轻快录音与交付版独立人声的片尾逐采样相同。[核对明细](checks.json)

**四项核价均读取实际交付件。** 海报从 PNG 的活动价格区域读字，片内字幕和价牌从 MP4 的实际画面读字，口播从 MP4 的最终混音独立听写，发布配文和 SRT 分别从下载的文件读取。原版读到「周五」和 18.90，新版读到同一到店条件和 19.90。字幕保留两位小数，配音读出日常说法。[完整读回和置信度](checks.json)

**积分按两次制作目的分别结算。** 首次创作 12 积分，余额 120 → 108。生成、下载和选择两段试听共 0 积分。本次改价并换片尾共 1 积分，余额 108 → 107。同一份修改确认在提交时、提交后和交付后共发送三次，服务端返回同一任务，流水只有一笔 1 积分消费。上述记录使用隔离测试账号。[积分与任务记录](checks.json)

复验从项目根目录运行 `.venv/bin/python scripts/proof-offer-ending.py`，使用本机已配置的视觉服务、中文表达配音、OCR、Whisper 和 FFmpeg，从新隔离数据库开始实际上传、确认和下载。[复验脚本](../../../../scripts/proof-offer-ending.py)

### 故意换错素材，验证交付前能拦住

从已通过验收的 19.90 元版复制出两份临时文件，分别调用服务交付前的同一套检查。第一份保留新版视频和配文，换入旧版海报。OCR 从 PNG 读到「周五到店价 ￥18.90」，海报检查拦截。第二份保留新版 H.264 画面、字幕和 19.90 元海报，用 FFmpeg 原样封装旧版 AAC。独立转写从这条 MP4 听到「周五到店，十八块九」，口播检查拦截。上方链接仍是两次正式流程实际交付的文件。

## 客户端和回归验收

420 像素宽的 Chrome 页面实际生成并加载了两段 WAV，可选中「轻快招呼」。网页生产构建通过，11 个小程序页面通过 WXML 编译，小程序 8 项本地回归通过。Python 全套 172 项，168 项通过、1 项跳过、3 项失败。改动前的基线复跑已记录同样三项失败，分别涉及签名提示词的保留、照片网格海报的可编辑图层与视频预检的短句期望。微信真机和生产发布均未在本轮验收。
