# 响指出片商业海报

交付一张顾客能看懂、商家能核对、目标渠道能直接使用的海报。先决定顾客要记住哪件事，再决定商品、字和光的位置。

小程序「今天的朋友圈」按[朋友圈实拍出稿标准](references/moments-workflow.md)执行和验收。

## 接一份简报

先区分商家是想看一个创意长什么样、要交付准确的商品广告，还是要剪一条短片。三种任务可以共用一句创意，但需要不同的生产指令。创意比较沿用同一商品原图、标题及画幅。一次只改一个变量，才能讨论差异来自模型、提示词还是执行方式。

1. **读原图。** 写下一个能指给别人看的细节，例如杯中两层液体的交界、机身上暴露的金属卡口。再单列商家确认的品名、价格、条件、标题和标识选区。有视觉预检时读取它对原图的观察。视觉观察可以支持构图，商业承诺需要商家资料。
2. **提出两个能画出来的想法。** 一个从商品的动作或用途出发，一个从照片里的形状、材料或负空间出发。分别用一句话讲清“观众看见什么，然后发现什么”。选与商品及标题联系更紧、现有素材能实现的一种。只有商家要求多个方案时才交付两套。
3. **找到一个有用的参考。** 点出原作里的具体位置，写出要借的关系，再写出这次替换成什么。比如 04 的上下两枚苹果用果梗夹出标题，给耳机借用的是头梁围出的负空间。直接照搬两件商品会改变商品数量的暗示。参考分工见[来源与创作判断](references/visual-study.md#重新组织创作-agent)。
4. **写一段美术指导。** 包含第一眼落点、一个动作、商品与字共用的边界、主色与局部对比、希望传达的情绪。颜色和字重回答当次目标。近景能承载全部信息时，字可以很小；优惠是主诉求时，单位和生效条件要随数字可读。

## 选择制作方式

| 商家要看什么 | 如何出图 | 用什么验收 |
| --- | --- | --- |
| 整张创意稿、模型直出对照 | 默认由百炼 Qwen-Image 生成整稿，输入商品原片、选定的画面构想、画幅及逐字文案。每个方案独立出一张，只给与商品有关的参考。商家点名 GPT Image 2 时选择该模型并核对任务回执。 | 打开实际成图，读中文，检查标识与结构，记录命题最可见和最薄弱的位置。 |
| 精确 SKU、促销条件、可改字源稿 | 走 Trupic 分层导出。完整照片保留现场；有透明主体时，环境可以重做。明确要求材质特写时，可放大主体内部的一块实拍纹理，保留完整商品作尺度参照。 | 原图像素、标识选区、标题、数字、印刷尺寸和可编辑图层。保真与构图分别检查。 |
| 印刷或品牌角色 | 孔版先选墨数，再从原图提取形状。IP 先锁定参考形象，再按地点、动作与对象组织场景。独立安排可读信息。 | 相同油墨只出一版。核对角色轮廓、配件、颜色及动作与场景的关系。 |
| 商品短片 | 写出三镜各自新交代的信息。例如先看完整杯身和奶纹，再切近它们的交界，最后回到可辨的整杯。切点有形状或方向承接。用实拍视频时才把真实搅拌、倾倒等物体动作写入执行清单。 | 看实际 MP4，核对首、中、尾镜与字幕、声音、停留时间。单张照片可做摄影机运动、景别与分层视差，物体自身的运动要有相应素材。 |

在应用里，确认方案时可查看整张直出指令草案。作品详情中的“整张海报直出提示词”使用该版本的标题、品牌和交易信息，供图像模型对照。正式分层生产另用场景指令。对直接看效果的请求，有可用图像工具时实际生成并展示。

在项目根目录用 `.venv/bin/python -m server.qwen_image --reference 商品原图.png --prompt-file 整图提示词.txt --size 1024x1536 --output 海报.png` 调用百炼。无参考图的概念稿省略 `--reference`。命令读取后台图像连接；也支持北京地域的 `DASHSCOPE_WORKSPACE_ID` 和 `DASHSCOPE_API_KEY`。实际收到 PNG 后才标记出图成功。Qwen3-VL 承担原图和成品审核。工作台的可编辑分层导出仍按商品保真流程执行。

## 选择字与信息层级

- **材质、慢生活与叙事**。用宋体做短主标题，让横细竖粗呼应釉面、玻璃或茶汤的细节。短中文允许纵排，混排型号和英文名横排。字数过长时换行，保留短语整体。
- **机械、数码与家化**。黑体的中粗笔画能在反光和小屏里保住轮廓。耳机可在一侧分两组排标题，汽车横向展开，家化用品让字在瓶盖上方收拢。
- **价格和日期**。数字可用窄体 Barlow Condensed；同一价格的小数、币种和单位应连续可读。价格是主诉求时，先用最大字级标出已确认的价格，再放品名和适用条件。多档价格应作为一个整体保留，不把原价误作活动价。不自行添加折扣、期限、性能、奖项或认证。
- **品牌字**。优先商家选定并有权使用的 TTF/OTF。检查真实字形覆盖，缺字逐字搭配思源黑体、思源宋体或数字字体。Hunter 可用来制作待导入的字体。用实际字号检查“春山 / Tea / 28.50元”，特别留意小数点、斜线和中英基线。
- **活动丝印**。围绕一个能代表活动的物件组织前后景，用有限色、网点、叠色和强轮廓做远读识别。商家上传的实拍商品保留原色。普通保洁、数码货架图和需要核对色号的底妆优先使用摄影。

## 行业和画幅

按当前任务查阅[本地原片与成稿、Pinterest 案例和指定仓库的分工](references/visual-study.md)。应用内的行业、关键词、示意图匹配、色值、字体角色、镜头说明与样张文案保存在 [directions.json](references/directions.json)。原创样张的无字底图可按[摄影简报](references/plate-prompts.md)重新制作。同一行业可以因投放目的切换设计方向，手动指定的版式优先。

逐张查阅[35 张海报与 Pinterest 参考拆解](references/poster-reference-review.md)。让食材或餐具带动视线时选「食欲定格」，实物较小且由局部光线交代材质时选「留白光影」，完整照片与画面边缘承担叙事时选「照片编排」。用实际商品轮廓、标题和投放条件复核选出的版式。

「照片编排」的同风格改稿参照项目内的 [layout-grid](../layout-grid/SKILL.md)。作品页保留取景框原稿，可把同一张照片改成满版摄影。先用交付字体量标题和交易信息，再为原片分配空间。照片边缘的光色延展到字区，横版重新安排阅读方向。

3:4 和 4:5 可用上下或侧边留白。9:16 要让标题和商品在纵轴上有接力关系，底部给行动文案留位置。1:1 先确定缩略图里的主体大小。16:9 优先设计横向背景；竖幅母图需要保全主体时，让原图光色延伸到字幕一侧。以最终画幅分别排字并检查主体边界。短片用同一套字色分三镜安排标题、主题细节和行动文案。

## 验收

- 手机缩略图下先读到什么？主体是商品造型、价格还是活动名？三者争抢时，按商家的目标缩小另外两项。
- 在原始尺寸看瓶盖、车轮、耳罩、包装字及品牌色有没有受裁切或文字遮挡。检查标题是否横跨高频纹理。将限制条件与已确认的经营资料逐字对照。
- 分别导出竖、方、横版本，核对 PNG 实际像素与 DPI、MP4 视频轨尺寸及帧率。DPI 决定相同像素对应的印刷尺寸；大幅实印要看实物照片原始分辨率。
- 变更行业规则或排版器后，在项目根目录运行 `.venv/bin/python .agents/skills/trupic-commercial-poster/scripts/proof.py --sheets /tmp/trupic-proofs`。它通过正式排版器重绘灵感广场的七张行业样张和四个同稿版式，可在指定目录对照成图。运行 `.venv/bin/python -m unittest discover -s tests -v` 验证生成、下载、经营条件及规格。

## 字也参与构图

当商家明确要字图穿插，或标题中的字恰好解释了照片里的动作时，才把字作为图形。菌盖可以截断一横，原片中的地平线可以充当字的基线。没有这种关系时保留主标题即可。中文、英文或型号按实际简报选择。图形字、交易信息和原图主体分别保留；适配横幅时重选负空间。

## 写标题和短片

**社交货币是创意主文案的首要选稿标准。** 从顾客的位置写第一行。想象他在摊前只看到商品和这句话，拿起手机，会把哪几个字拍给哪个人？那个人能顺口接什么？例如「嘴硬的人，切的水果最整齐。」果盘接住了「嘴硬」，收图的人也许会回「我爸还会把盘子往我这边推」。同行提醒、打趣、表达心意和分享发现都可以成为动机，应当贴合具体商品和品牌语气。把接话留在内部，只将胜出的句子放到海报主标题、社媒首行或短片首镜。商家有指定标题、规格或交易通知时按原要求交付。

参考 [hiccai-wenan](https://github.com/laixi969-coder/hiccai-wenan) 的商品事实与媒介适配方法。同一商品可以从一个具体动作、一个购买选择或一个生活时刻切入。先尝试把商品换掉，检查标题还说不说得通。把照片已经告诉顾客的形状留给画面，把观看理由、使用选择或真实活动条件留给文字。顾客能做的动作比「发现更多精彩」更适合结尾。指定标题原样落版。

先从商家资料中划出支撑标题的一条卖点，写下它改变的一个动作。设想顾客做这个动作时最想向谁表达哪种情绪。例如后排能放倒，让帮朋友搬家的人有底气回一句「纸箱先别拆」。拿走这个功能，检查这句帮忙的话还有没有同样的分量。受众换为返乡子女时，要重新找一句家里人会接的话。未给定卖点时，用可以确认的产品用途；把情绪当作创作角度，避免冒充真实评价。离线选稿使用[卖点与分享情境](references/benefit-scenes.json)。

标题选定后，按[商业文案的收口](references/closing-copy.md)把它接到商家要的一个动作。

参考 [hiccai-douyin](https://github.com/laixi969-coder/hiccai-douyin) 的开场与镜头推进，按本产品的九秒长度落地。0–3 秒用近景提出值得留下来的问题或观察，3–6 秒切到相关细节并给出新的信息，6–9 秒回到全景、行动及适用条件。把声音留给节拍，静音播放也应读得懂。逐镜核对实际 MP4 和作品页里的分镜。真实播放和转化效果以发布后的数据衡量。

[本地创意方向](references/copy-directions.json) 含产品线索、三种标题切口、正文和中段字幕。外接文案模型时，使用商家资料重新起稿并复核承诺。示例信息只用于样张。
