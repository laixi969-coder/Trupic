# 响指出片商业海报

交付一张顾客能看懂、商家能核对、目标渠道能直接使用的海报。先决定顾客要记住哪件事，再决定商品、字和光的位置。

## 形成画面

1. 从经营资料里分别取出商品名、品牌、主张、行动指引和必须保留的限制。区分单品上新、价格活动、品牌叙事和门店活动。把创作指令留在工作区，交付画面只排给顾客看的文字。缺少售价时以标题领读。
2. 写出一句取景说明，点明主体、动作或状态、环境以及留给文字的部位。例如“侧逆光穿过抹茶和奶层，杯口在右，下方台面承接订购信息”。以同一张连续画面覆盖整张画布。去掉标题栏、图片区、卖点框后，主体和光线仍应能表达商品。
3. 需要准确识别 SKU 时，取商家原图，保留瓶型、包装字、商标、颜色和配件形状。实物有完整摄影构图时延展边缘光色；核对过的透明主体可合成到新台面。商家没有供图时，选相符的概念素材并标示“创意场景示意”。缺乏匹配图像时使用文字构图，或在已配置的服务中制作原创场景。
4. 把素材缩到手机列表里的大小。找出最先看到的轮廓，沿轮廓的切线、环境的明暗边界或一个安静的负空间放标题。车身水平线、杯壁垂直线、耳机头梁弧线可以导向完全不同的读法。
5. 从实物取主色，让场景延续或衬托主色。给小字挑稳定的明暗区。远读信息最多一个视觉重音，其他信息沿一条边缘或同一条基线收束。

## 选择字与信息层级

- **材质、慢生活与叙事**。用宋体做短主标题，让横细竖粗呼应釉面、玻璃或茶汤的细节。短中文允许纵排，混排型号和英文名横排。字数过长时换行，保留短语整体。
- **机械、数码与家化**。黑体的中粗笔画能在反光和小屏里保住轮廓。耳机可在一侧分两组排标题，汽车横向展开，家化用品让字在瓶盖上方收拢。
- **价格和日期**。数字可用窄体 Barlow Condensed；同一价格的小数、币种和单位应连续可读。价格是主诉求时，先用最大字级标出已确认的价格，再放品名和适用条件。多档价格应作为一个整体保留，不把原价误作活动价。不自行添加折扣、期限、性能、奖项或认证。
- **品牌字**。优先商家选定并有权使用的 TTF/OTF。检查真实字形覆盖，缺字逐字搭配思源黑体、思源宋体或数字字体。Hunter 可用来制作待导入的字体。用实际字号检查“春山 / Tea / 28.50元”，特别留意小数点、斜线和中英基线。
- **活动丝印**。围绕一个能代表活动的物件组织前后景，用有限色、网点、叠色和强轮廓做远读识别。商家上传的实拍商品保留原色。普通保洁、数码货架图和需要核对色号的底妆优先使用摄影。

## 行业和画幅

先读[七类 Pinterest 案例和四套 Skill 的取舍](references/visual-study.md)。应用内的行业、关键词、示意图匹配、色值、字体角色、镜头说明与样张文案保存在 [directions.json](references/directions.json)。原创样张的无字底图可按[摄影简报](references/plate-prompts.md)重新制作。同一行业可以因投放目的切换设计方向，手动指定的版式优先。

3:4 和 4:5 可用上下或侧边留白。9:16 要让标题和商品在纵轴上有接力关系，底部给行动文案留位置。1:1 先确定缩略图里的主体大小。16:9 优先设计横向背景；竖幅母图需要保全主体时，让原图光色延伸到字幕一侧。以最终画幅分别排字并检查主体边界。短片用同一套字色分三镜安排标题、主题细节和行动文案。

## 验收

- 手机缩略图下先读到什么？主体是商品造型、价格还是活动名？三者争抢时，按商家的目标缩小另外两项。
- 在原始尺寸看瓶盖、车轮、耳罩、包装字及品牌色有没有受裁切或文字遮挡。检查标题是否横跨高频纹理。将限制条件与已确认的经营资料逐字对照。
- 分别导出竖、方、横版本，核对 PNG 实际像素与 DPI、MP4 视频轨尺寸及帧率。DPI 决定相同像素对应的印刷尺寸；大幅实印要看实物照片原始分辨率。
- 变更行业规则或排版器后，在项目根目录运行 `.venv/bin/python .agents/skills/trupic-commercial-poster/scripts/proof.py --sheets /tmp/trupic-proofs`。它通过正式排版器重绘灵感广场的七张行业样张和四个同稿版式，可在指定目录对照成图。运行 `.venv/bin/python -m unittest discover -s tests -v` 验证生成、下载、经营条件及规格。

## 字也参与构图

从商品动作、材料或用途里各取一个汉字和一个短英文词。例如杯中用「茶 / MATCHA」，耳机用「声 / SOUND」。选择一种笔形做主要图形，另一种可以成为旋转的小边注。中文可以放大为负形，英文可以横向展开、出血或做空心线条。字的宽窄、笔画重量和遮挡关系由实物轮廓决定。价格和限制始终使用另外一层可读文字。

在七张原创行业图上，将字形绘入环境，然后用主体蒙版还原杯身、耳罩、车身或包装，形成真实的前后关系。商家自己的照片用边缘留白安置图形字，优先保护实物。工作台可选随构图搭配、中英文组合、中文大字、英文造型字或关闭。

## 写标题和短片

**社交货币是创意主文案的首要选稿标准。** 从顾客的位置写第一行。想象他在摊前只看到商品和这句话，拿起手机，会把哪几个字拍给哪个人？那个人能顺口接什么？例如「嘴硬的人，切的水果最整齐。」果盘接住了「嘴硬」，收图的人也许会回「我爸还会把盘子往我这边推」。同行提醒、打趣、表达心意和分享发现都可以成为动机，应当贴合具体商品和品牌语气。把接话留在内部，只将胜出的句子放到海报主标题、社媒首行或短片首镜。商家有指定标题、规格或交易通知时按原要求交付。

参考 [hiccai-wenan](https://github.com/laixi969-coder/hiccai-wenan) 的商品事实与媒介适配方法。同一商品可以从一个具体动作、一个购买选择或一个生活时刻切入。先尝试把商品换掉，检查标题还说不说得通。把照片已经告诉顾客的形状留给画面，把观看理由、使用选择或真实活动条件留给文字。顾客能做的动作比「发现更多精彩」更适合结尾。指定标题原样落版。

先从商家资料中划出支撑标题的一条卖点，写下它改变的一个动作。设想顾客做这个动作时最想向谁表达哪种情绪。例如后排能放倒，让帮朋友搬家的人有底气回一句「纸箱先别拆」。拿走这个功能，检查这句帮忙的话还有没有同样的分量。受众换为返乡子女时，要重新找一句家里人会接的话。未给定卖点时，用可以确认的产品用途；把情绪当作创作角度，避免冒充真实评价。离线选稿使用[卖点与分享情境](references/benefit-scenes.json)。

标题选定后，按[商业文案的收口](references/closing-copy.md)把它接到商家要的一个动作。

参考 [hiccai-douyin](https://github.com/laixi969-coder/hiccai-douyin) 的开场与镜头推进，按本产品的九秒长度落地。0–3 秒用近景提出值得留下来的问题或观察，3–6 秒切到相关细节并给出新的信息，6–9 秒回到全景、行动及适用条件。把声音留给节拍，静音播放也应读得懂。逐镜核对实际 MP4 和作品页里的分镜。真实播放和转化效果以发布后的数据衡量。

[本地创意方向](references/copy-directions.json) 含产品线索、三种标题切口、正文和中段字幕。外接文案模型时，使用商家资料重新起稿并复核承诺。示例信息只用于样张。
