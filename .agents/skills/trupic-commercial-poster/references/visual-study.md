## 应用与核验

可在灵感广场点开每张行业海报的“用色与排版”，查看排版色、字体组合与商品识别要点，再将构图带入自己的草稿。样张由原创无字概念底图与正式排版器生成，示例品牌与折扣不会随构图写入商家资料。源站作品用作构图研究，产品里显示原创演示素材。

复核时先在手机宽度看一次，写下“第一个看见的东西”。再看原尺寸，逐项核对品牌字、折扣小数和单位、限制条件、商品轮廓。最后把同稿换成横版，确认文字落点和物件边界随画幅重新安排。

## 从原片决定字放在哪里

本次本地研究覆盖 35 个文件。8 张为原片，26 张是不同的成稿，另有一张摇马成稿与前一张字节相同。对照摇马、手持雏菊、石材、树与倒影、俯视草坪、牛群、成都玻璃建筑和洱海骑手这八组，可直接辨认设计师改变了什么。

| 原片线索 | 成稿中的决定 | 在商家方案中核对 |
| --- | --- | --- |
| 黄摇马、蓝座、红弹簧 | 保留黄马，整片环境改由蓝色承接，弹簧的摆动成为环绕文字的椭圆。 | 选色时说明主体色、环境色和小重音各来自哪里。 |
| 手握小花、草坡横线 | 花被解释为入场券，票名字落在天空，手势和花形共同引到小花。 | 商品可承载的比喻是否能用上传素材看出来？ |
| 粗石与硬投影 | 裁近触感，文字框的一条边顺着石面切线。 | 可以裁纹理，保真区域和交易条件仍需清楚。 |
| 树与水面 | 以岸线为折轴，树、山形、部分表现字成正反对应。 | 倒影有实际依据，保留一处正向标题。 |
| 双脚与草影 | 俯视视角被解释为草坪观众席，声波和小方窗指向观察点。 | 符号只服务一个体验，勿把装饰误作可交互控件。 |
| 牛背与树线 | 手绘描边紧贴背脊，白标题置于深林，深绿色下一句落到浅草。 | 先检查字后方局部明度，再确定字色与位置。 |
| 建筑立面接缝 | 白引线沿消失点延伸，荧黄小块平衡构图，信息字保持水平。 | 运动方向可借建筑，阅读方向仍要稳定。 |
| 骑手与道路 | 天空容纳旅行题，路面箭头顺着车轮前进方向。 | 行进方向留出空间，镜头切换沿同一轴线。 |

Pinterest 两个搜索页中，红苹果的果皮刻字让商品材质直接参与标题；菌菇与纵横文字相扣，与本地 01 为同一设计；红字“躺平”与人物身体、椅子形成上下倒置的玩笑。日本美食页同时出现暗调酒器与海鲜、芥末黄色炸虾。前者用克制的小亮部、暗底与底端题字组织幽静感，后者用长虾对角线、倾斜粗字与横向价签表达热烈。把“日式”直接翻译为留白或统一配色，会漏掉两种完全不同的设计任务。[苹果刻字](https://www.pinterest.com/pin/852869248233885594/) · [菌菇](https://www.pinterest.com/pin/586805026489136345/) · [日本美食搜索](https://www.pinterest.com/search/pins/?q=%E7%BE%8E%E9%A3%9F%E6%B5%B7%E6%8A%A5&add_refine=%E6%97%A5%E6%9C%AC%7Cguide%7Cword%7C4)

相机「取景投影」使用从卡口朝画外展开的风景，真实机身压住档案中的型号字，主标题落在光束下缘。食材「字形与实物穿插」读取已确认的食材名，实物在前、放大的宋体食材字在后，纸色与墨色取自上传的主体。需要保留完整原图时，保留整张照片；有独立主体蒙版时才可让字进入主体后方。作品的源稿保留这些位置关系。

## 重新组织创作 agent

这次重新看了本地目录全部 35 个文件。8 张原片和 26 张不同成稿提供了两种证据：成稿说明视觉效果，原片与成稿的配对说明设计师具体改了哪里。17 与 21 是同一张摇马成稿。四张商业参考和练习海报承担不同的任务，不宜用同一条“留白越多越好”来评价。

| 看原片或成稿时问什么 | 能看到的差异 | 给商家工作的启示 |

| 视觉动作来自哪里 | 02 中筷子与碗具有高低差，碎屑让人预感下落；20→21 让字沿弹簧的摆幅转动。 | 食欲可以来自悬停、滴落、搅动。先确认实物和素材能否支撑动作，再定字的方向。 |
