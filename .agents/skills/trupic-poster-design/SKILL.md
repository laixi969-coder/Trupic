# 海报设计

参考入口：[Lovart 海报设计](https://www.lovart.ai/zh/skills)，页面作者 LiamHustle01，2026-11-22 查看。页面展示概念到交付的范围与海报示例，更多菜单只观察到分享入口。未取得原始 SKILL.md 或内部工作流；本文件是 Trupic 自有方法与公开示例观察的适配。

先读 [Trupic 商业海报](../trupic-commercial-poster/SKILL.md) 的制作与验收规则，再按本次原图和目标确定一个传播命题。单独记录不可改的商品名称、指定标题、价格、期限、规格和标识。

文案与画面同时构思：比较商品用途与实物形态两条切入方式，选择商品联系更紧的一条。明确观众先看见什么、标题补充什么、随后采取什么行动。以这一关系组织构图，而不是把同一照片与同一长段文案机械地放进模板。

公开示例中的可借用关系：饮料广告用大标题、单独的优惠区域和完整商品形成层级；生活题材海报用现场光线与较轻的文字建立情绪；人物海报通过光线和视线连接标题与主体。借用关系，不复制品牌、优惠、人物或经营声明。

输出前，画面执行者反馈标题空间、商品遮挡与裁切风险；文案执行者可调整表达长度，但保留锁定事实。不同画幅重排，横幅采用横向关系。价格是主诉求时数字、单位与条件一起可读。

按运行环境选择执行方式：本次不接外部 API 时，使用 Trupic 现有原图保真、排版和分层导出；需要模型重绘、未知角度或真实物体动作时，明确尚需的能力和素材。方法文件本身不会增加这些执行能力。

交付检查真实成图：缩略图主诉求、原尺寸字形和数字、商品轮廓与包装标识、活动条件、PNG 尺寸以及适用的 SVG 图层。失败项局部重做并复检。运行时条目为 `poster_design`，由一句话海报流程自动选用，完整定义见 [方法目录](../trupic-creative-library/references/catalog.json)。

首稿和改稿的阅读顺序、取景与文字容量由 [layout-grid](../layout-grid/SKILL.md) 统一执行。
