# 审美刻意训练

把审美判断落实到观看者的体验。回答“我先看到了什么，是什么让我看过去，这个顺序对作品的目的有什么影响”。保留作品已经奏效的选择。

## 拿到任务后

- **有成稿要评。** 先按目标尺寸看整张，记下第一眼与第二眼，再放大检查判断依据。如果用户给了 A/B 两稿，沿同一用途和观看条件比较，说明哪稿更合适、取舍在哪里。
- **有参考要借鉴。** 拆出能迁移的一条关系，用用户自己的题材、文案和图像给出新方案。具体练法见[拆解与训练](references/practice.md)。
- **只有题目要定方向。** 用受众、载体、必读信息和所需情绪决定视觉主角。交付能直接开工的布局、用字、光色决定和检查方法。需要选风格或查方法时读[白皮书方法笔记](references/whitepaper.md)。
- **要练习。** 选与用户当前短板相关的作品和一个变量。说明练什么、怎样做、有何可观察的进步。支持单次练习和分次复盘。
- 用户说“高级”“松弛”“有冲击力”时，把词落在具体对象上。例如纸张要显出纤维，人物要显得亲近，活动名要在手机上先被读到。有图就先看图。只有文案或描述时，说明依据，给出待验证的方案。

## 遇到两种都说得通的改法

翻到[五十例对读](references/poster-cases.md)，选与当前作品面临同一问题的一对。说出两种做法各自保护了什么，再依用途作选择。评审者想“删掉杂乱背景”时，先查它是否还承担名单、节庆气氛或城市密度；想“把标题全部拉齐”时，先查错位是否表现声音、时间或运动。只要能满足请求，就不必给用户复述案例史。

看图时分清原作、拆解示意和作者解说。只用原作判定字体、颜色和位置。遇到图文相左，指出可见笔画或具体区域，保留不确定的部分。涉及注意力与传播效果时，区分自己的观看记录、根据版面作出的预测和真实读者反馈。

## 怎样看一张作品

1. **确定任务。** 谁在什么距离、什么尺寸观看？希望他先理解什么、记住什么？缺少背景且仍能推进时，用一句话写明假设。
2. **画出版面骨架。** 暂时忽略图案，把图、标题、说明当成几个块。指出重心、分区、对齐线、疏密或裁切。说清视线从何处进入，又在哪里分叉或停住。满版和留白都可能成立。
3. **沿阅读路径查原因。** 看字号、字重、字距及行距怎样分层。再看色彩的面积、明度和饱和度如何争夺注意。最后看肌理、装饰线、图文叠压是否传达题意。照片优先看主体、光向、明暗交界、景深和背景关系，文字分析只在有字时使用。
4. **做一个能推翻判断的试验。** 按问题选缩略图、灰度、遮挡某元素、只改一个变量的前后对照。先预测可见变化，再检查。用户没提供修改稿时，把效果写成预期，和已经观察到的事实分开。
5. **交付最有影响的决定。** 写清位置、可见现象、观看后果、改法和验收条件。标出值得保留的细节。短评可以只讲一个决定，复杂成稿再分主次。别用脱离目的的美丑分数代替解释。

**反馈示例。** “右上角的橙色日期是全图唯一的暖色，我先读到了日期，随后才找到展名。若这张图用于展览首发，保留日期位置，把它改成与说明文字相同的深灰。缩回双列信息流大小，请另一人说出第一眼读到的词。若用于最后一天提醒，日期先被看到反而符合任务。”

当用户要求实际制作或修改时，把上述判断落实到交付物；当用户只要点评时，给出足以执行的修改说明。
