# Trupic 创作方法库

先确定商家的交付目标与已有素材，再从 [catalog.json](references/catalog.json) 读取匹配条目。只将该条目的输入、执行指导、验收规则与限制带入任务，不把全部技能一起注入创作。

`workflow` 表示已接入本地素材包；`integrated` 表示方法已进入现有单图或短片策划；`reserve` 仅保存方法，尚无完整执行路径。储备条目不能自动标成可生成或直接提交收费任务。选择媒介由用户目标决定，不因发现视频技能而把图片任务变成视频。

每个条目的 `source` 记录参考入口和观察日期。这些是 Trupic 编写的本地适配方法，未取得 Lovart 内部定义，不是原版技能包。没有拷贝示例图片、私人项目或作者未公开的提示词。不调用 Lovart API。

海报任务使用 [海报设计](../trupic-poster-design/SKILL.md)，商品保真与排版执行规则使用 [商业海报](../trupic-commercial-poster/SKILL.md)。其他业务查 catalog 中匹配条目的 instructions；扩展任务如详情页、网站、角色设定须先检查 limits。

文案和画面共用商品事实、目标受众、核心命题及版式约束。文案为画面保留可读空间，画面反馈标题长度与遮挡问题。价格、规格和限定条件不参与创意改写。视频增加统一的镜头编号、时间、画面动作、字幕与声音指令。

运行时由 `server/skill_library.py` 选择并保存条目版本、阶段指令与验收条件。运营后台展示完整方法与限制；用户仅看到任务、成品和修改入口。
