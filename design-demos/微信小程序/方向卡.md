# 首页入口

| 候选 | 使用情境与主屏 | 动作、视觉与取舍 |
|---|---|---|
| A 开单台 | 商家已经知道推广什么，先写需求 | 用微信表单的信息顺序，输入与规格在同一处，品牌绿标记下一步。样张排在下方。 |
| B 灵感选集 | 看图才有想法，先挑行业和成品 | 从编辑选片的思路出发，双列成品按内容错落，点图带入需求。 |
| C 画面创作台 | 手边已有商品，先确定画面 | 借摄影师选片时的大预览与缩略图序列。暗底把注意力留给画面，底部保持单手操作。 |
| 素材清单 | 微信列表分组，一行对应一种原料 | 适合资产管理，作为创作首页多了一层选择。 |
| 用量面板 | 轮盘应用样张 04，以清楚的数字展示用量 | 适合账户页，积分不宜抢占创作入口。 |
| 档期日历 | 轮盘东亚样张 04，把档期当作首页骨架 | 节庆项目适合日历，日常临时创作的步骤偏多。 |
