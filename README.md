# 响指出片 Trupic

商家可以在营销助理里用一句话发起文案、海报或短片任务，在对话内补充素材、选稿、确认积分和查看成品。手机网页和微信小程序共享商家账号、作品与进度。

首页的「新对话」可以关联活动项目。「助理记忆」保存经商家确认的资料和偏好。试用时可输入“为茶馆做一张海报，文案用「下班来喝茶」”，核对报价再制作。原工作台可从页底进入，也支持直接打开 `#studio`。

当前功能、复验步骤与真实服务验收条件见 [PRD 验收进度](PRD-验收进度.md)。部署和存储说明见 [系统架构](ARCHITECTURE.md)、[架构决策](ADR.md) 和 [环境变量示例](.env.example)。

## 启动

当前项目使用 React、Vite、Flask、SQLite、Pillow 和 FFmpeg。在项目目录执行以下命令。需要 Node.js 22.12 或更新版本、npm、uv，以及带 ffprobe 的 FFmpeg。

```sh
npm ci
npm run setup
npm run build
npm start
```

打开 [本地工作台](http://127.0.0.1:7341)。开发模式使用 `npm run dev`，前端默认使用 7341 端口，API 使用 7342。构建模式只需要一个服务进程，可通过 `PORT` 更改端口。

在 macOS 14 及以上版本，安装脚本会用 Swift 编译系统 Vision 主体分割工具。Linux 环境可通过 `TRUPIC_CJK_FONT` 指定简体中文字体。系统无法使用主体分割时，应用保留原图。

## 微信小程序

微信开发者工具导入本仓库根目录。项目配置指向 `miniprogram/`，采用原生 WXML、WXSS 和 JavaScript。底部「创作」可直接说需求、打字或拍照选图。点「说需求」听写，核对文字后发送；点「连续语音对话」后，每次停顿会自动转写发送，助理朗读回复后继续听，点「结束通话」或离开页面即结束。「接着做」可回到对应商家的待办和报价。制作积分仍需在任务卡上点「确认制作」。

点「实拍朋友圈与其他创作」进入原拍照流程。拍摄或选择一张照片，可补充一句话，点击带积分的生成按钮即可得到原图排版和配文。结果页可以保存图片、复制配文、选稿和换版式。首页另有「图片文字一键」和「视频文字一键」：图文可选一张或两张、带形状图示的画幅并显示各自积分；视频可选 15 秒，有效订阅另有 30／45 秒。确认总价、海报先选一组候选文案后开始制作，进度页逐项显示阶段、失败项退回积分并可单独重试，成品可复制文案或保存到相册。「其他创作」可进入原有海报、文案和短片流程，需要标注保真区域的商品图会交接到这里核对。「灵感」可以按行业筛选并带入样张方向。「我的」可绑定或登录账号、多选经营行业（可自定义）、管理作品（勾选、全部删除，八秒内可撤销）、查看积分明细、一键创作记录和任务，并进入「套餐与积分」浏览套餐与订单；付款链接复制后在浏览器完成支付。

朋友圈默认导出 1080 × 1440，可选 1080 × 1920。产品交互、文案选稿、海报制作及实拍回归依照[朋友圈实拍出稿标准](.agents/skills/trupic-commercial-poster/references/moments-workflow.md)。

- 本地联调先按上文启动服务。开发版默认访问 `http://127.0.0.1:7341`，开发者工具连接本机 HTTP 时，在本地设置中开启“不校验合法域名”。手机访问时使用手机可达的业务服务地址。
- 项目默认使用测试标识 `touristappid`。真机体验和发布使用自己的小程序 AppID，在 `miniprogram/config.js` 填写已部署的 HTTPS 服务地址，并在微信公众平台配置 request、uploadFile 和 downloadFile 合法域名。开发者工具的个人设置保存在被 Git 忽略的 `project.private.config.json`。
- 商家数据由现有 Flask 接口保存。服务使用独立签名会话辨识工作空间，方案确认后按服务返回的积分提交，生成结果支持复制文案或保存图片、短片到相册。
- 小程序流程和语音控制测试运行 `node --test tests/miniprogram.cjs tests/miniprogram-voice.cjs`。测试模拟微信平台接口，使用独立临时数据库启动真实后端，验证生成和导出。后端回归运行 `.venv/bin/python -m unittest discover -s tests`。

### 本地语音服务

营销助理的语音输入需要 FFmpeg、whisper.cpp 的 `whisper-cli` 和支持中文的多语 GGML 模型（如 `ggml-small.bin`）。在服务进程环境中设置 `TRUPIC_WHISPER_MODEL` 指向模型文件，或将其放在项目的 `.trupic/models/ggml-small.bin`。CLI 可通过 `TRUPIC_WHISPER_CLI` 指定，也可放在 `.trupic/bin/whisper-cli` 或系统 PATH 中。这两个项目内路径都支持软链接。中文回复使用 macOS `say` 的 Tingting 嗓音，Linux 使用 `espeak-ng` 的 `cmn` 嗓音，可用 `TRUPIC_TTS_VOICE` 调整。语音请求沿用 V4 工作空间会话，每段录音最多 60 秒、6 MB，每次朗读最多 600 字。转写只返回文字，朗读返回 MP3，临时音频在请求结束时清理。

## 商家操作

1. 在原创作台选「图片文字一键」或「视频文字一键」，输入需求。商家名称、商品照片均可留空。「商家档案」可多选行业、自定义行业；「宣传用途与商品」用于指定本次的推广对象。
2. 选择带形状图示的画幅。图文可选一张或两张海报，均配发布文案。可批量上传，核对自动建议的商品、风格和构图来源。上传获得授权的参考视频可以辅助安排镜头节奏。视频体验档为 15 秒，有效订阅可选 30 或 45 秒；较长视频需要足够的不同卖点或场景。30／45 秒短片在已连接文案模型时另写开场钩子与结尾行动句，与 15 秒版不同；草稿含未经商家确认的数字或承诺时沿用原句。
3. 核对交付项和总积分后开始。任务按成品预占积分，交付后结算，失败项释放预占，可单独重试。刷新后可从历史继续查看，视频默认静音。旧组合制作接口仍支持选稿和九秒作品。
4. 在作品页可点选新版海报的文字、缩短文案、指定价格替换、换画面、恢复旧版本，或保留原需求换画幅另存。「换一张」保留文案：有实拍图的作品只换版式并沿用底图，没有实拍图的作品重新生成配图。修改先报总价，取消不扣。历史支持逐条、勾选及全部删除，可撤销上一批。
5. 右上角「积分」显示余额、任务预占与退回记录、套餐和订单。「邀请与推广」提供绑定账号后的邀请链接与二维码，渠道账号另外显示授权范围内的客户与佣金。

### 内测计价、订阅与收款接入

「运营管理 → 积分与套餐」维护体验额度、有效天数、单张图片、各档视频和每次修改的积分。签发的报价保留当时的计价版本。月付和年付可分别上架；套餐按月发放，积分包仅供有效订阅补充。体验、订阅、购买和赠送分批记录，优先使用最早到期的积分。未注册访客的体验积分按网络每日限量发放（默认每 24 小时 5 份，`TRUPIC_TRIAL_PER_DAY`，0 为不限制；服务前有反向代理时设 `TRUPIC_TRUST_PROXY=1` 才按真实访客计数），用完后页面提示次日恢复或注册、购买，注册或登录时若额度已恢复会自动补发。旧库余额迁移为无新增到期日的历史批次。各套餐共享同一制作与审核链路。

默认套餐目录为空，邀请奖励和佣金为零。邀请人和代理可分别归属同一商家。商家在「邀请与推广」分享商家码、渠道码或联合链接，小程序在「我的」分享。「渠道与增长」可配置活动期限、两阶段双方奖励、叠加或优先方式、首单与续费佣金、结算等待天数，核实唯一商户编号、分配渠道权限及核查归属冲突。平台按优惠后实收计算佣金，人工登记结算。全额退款后，待结算佣金冲回，已结算佣金标记待追回。「商家与权限」支持客服、财务、运营角色与带业务单号的积分调整；财务人员不能调整本人账号的积分。超级管理员、财务和客服可以查看单个商家的档案与行业、最近任务、订单和积分流水。

收款接入使用部署方提供的支付桥接服务。配置 `TRUPIC_CHECKOUT_URL` 为收银台 HTTPS 前缀，配置 `TRUPIC_PAYMENT_SECRET` 为与桥接服务共享的强随机密钥。浏览器打开收银台前缀加订单 ID。桥接服务用签名 GET 请求读取 `/api/payments/orders/<id>` 的实收金额与币种，核实支付机构结果后再 POST 到 `/api/payments/webhook`。平台支持已支付、关闭未付款订单、原凭证全额退款三种通知。接入微信支付还需部署方实现微信侧验签和对账。

签名头为 `X-Payment-Timestamp`（Unix 秒）与 `X-Payment-Signature`（HMAC-SHA256 小写十六进制）。签名消息为时间戳、一个英文句点、原始请求体；查单 GET 的消息体部分使用 `GET /api/payments/orders/<id>`。回调以 JSON 提交 `order`、`status`（`paid`、`cancelled` 或 `refunded`）、`currency`（CNY）、整数分 `cents` 和 `receipt`。支付桥可随签名回调提交渠道侧稳定的付款人标识 `payerReference` 和已核验的平台登录名 `payerLogin`。同一凭据跨商家使用或关联推广方代付时，后台核对依据后处理推广奖励和佣金。退款应传原支付凭证。五分钟内接受有效签名，重复通知由订单和积分批次去重。配置收银台或录入商品不会产生实际收款。

正式模型路由可用 `TRUPIC_MODEL_STAGE=production` 启用。管理员在「模型平台」测试具体能力，再登记发行来源、日期、系列版本、该系列最低版本及质量成本核验记录。正式模式仅选用通过该连接实际测试、日期已核实且达到系列门槛的模型，未配置时使用本地路径。内测默认保留旧连接，便于迁移前核验。

复现一键流程的同商品验收：`.venv/bin/python scripts/proof-auto-create.py`。使用春山抹茶粉演示插画，在独立工作空间生成文案、四张图片和短片，并检查整套下载。

### 运行与恢复

任务线程中断后，服务每分钟检查处于「制作中」却没有工作线程的任务并重新排队，积分只预占一次；同一任务连续两次丢失线程时退回预占积分并提示重试。后台循环（每周选题、活动同步、云文件镜像、任务恢复）遇到异常会记录日志并在下一轮继续，不会静默停止。模型调用失败会记录原因类别（如 `HTTP 429`、`timeout`、`invalid_output`），「模型平台 → 高级设置与用量」显示当日失败原因。

同一平台同一能力的最近几次调用全部失败时暂停使用它，只走备用连接，冷却后自动重试主连接；默认 3 次、120 秒，可用 `TRUPIC_BREAKER_FAILURES`、`TRUPIC_BREAKER_SECONDS` 调整（次数为 0 即关闭），「模型平台」会显示熔断中的平台。设置 `TRUPIC_SECRET_KEY` 后，后台保存的供应商密钥和 `integrations.json` 中的密钥以 AES-GCM 加密落盘，接口仍只返回是否已配置；未设置时保持明文，后台会提示。

登录连续失败达到次数后，同一来源对同一账号暂停十分钟，可用 `TRUPIC_SIGNIN_FAILURES` 调整（0 为不限制）。未付款订单默认两小时后关闭并退回占用的优惠券，可用 `TRUPIC_ORDER_TTL_MINUTES` 调整；订单关闭后才到账的付款仍会发放权益，并进入「渠道与增长 → 付款核对」。

## 模型与素材

### 后台创作技能库

「运营管理 → 技能库」保存 24 项本地创作方法：9 类素材包、5 类接入现有创作流程的方法、10 类尚未接入生成的方法储备。各项包含输入要求、文案/画面/视频指导、验收条件、版本、参考来源和执行限制。超级管理员还可上传声明式 JSON 技能，填写标识、媒介、关键词、内置依赖和四项阶段指导。在固定测试通过后，可灰度、发布、停用或回退。普通用户不需要选择这些内部技能。

海报设计自动进入「一句话创作」的海报流程；封面、横幅和投放广告按需求匹配，短片加入商品广告分镜。策划把同一份方法指导传给文案与画面，作品版本保留当时的技能记录。储备方法不会自动进入生成或计费任务。原创作台提供图文和视频两种入口，原素材包接口保留兼容。一键流程按后台保存的文案、图片、视频和视觉审核连接分别调用模型。文案必须由文字模型写出并通过独立复核：未配置文字模型时（macOS 上可改用设备端模型），一键创作会提示先启用文字模型，不再用本地模板顶替。图片、视频和视觉审核未配置时使用本地排版与像素检查。包含海报时先由文案技能写出不同切口并独立复核。服务端把选稿绑定到本次方案，整套制作及失败重试沿用所选稿。云端连接中断可单项重试。海报候选不足两组时提示重试。旧版单项接口仍支持本地创意规则。旧版接口制作九秒三镜短片，新版按所选时长安排三、五或七镜，均为 24 fps 并含字幕与配乐；云端视频生成动态环境，商品原图与字幕仍精确合成。

定义位于 [.agents/skills/trupic-creative-library/SKILL.md](.agents/skills/trupic-creative-library/SKILL.md)；海报专项位于 [.agents/skills/trupic-poster-design/SKILL.md](.agents/skills/trupic-poster-design/SKILL.md)。Lovart 相关内容是参考公开展示编写的本地适配，未取得其原始技能定义，不调用 Lovart API。方法入库不意味着对应模型、平台发布或专用导出能力已经实现。

默认配置可以离线启动，但一键创作的文案需要文字模型。创意引擎结合原始需求、商家档案、消费场景、近期角度和已启用的策略生成文案，并使用原图或带示意标识的场景图制作成品。素材处理支持清晰度与曝光检测、保守调光、主体分割和摄影背景合成。针对包装或外观还原的请求需要真实商品原图。

创作模型统一在「运营管理 → 模型平台」配置；RSS / Atom 与 Pinterest 位于「运营管理 → 参考素材来源」。原「服务连接」中的模型表单已移除，旧连接和部署环境变量仍保持兼容。

| 能力 | 配置 |
| --- | --- |
| 文案模型与复核 | 填写 Base URL 和 API Key，同步并选择文案模型。首次调用创作文案，再单独发起事实与表达复核。海报选稿优先使用配置的文案模型。未指定模型时可使用已启动的项目本机 Qwen 服务（见 `npm run vision:serve`）；模型不可用或候选不足时停在选稿环节。 |
| 图像生成 | 支持 Images Generations、返回 `data[0].b64_json` 的接口、图像模型及对应密钥。常规分层导出发送创意描述生成背景或概念配图。小程序朋友圈在配置 GPT Image 或百炼 Qwen-Image 时，也发送去除元数据的缩小原片作为布景参考，再叠加实拍主体与逐字标题；离线可用随项目提供的无字布景。商家原图的主体在本地合成。商业海报 agent 的整图入口 `python -m server.qwen_image` 支持百炼 `qwen-image-3.0-pro` 和 `qwen-image-3.0`，可随提示词发送指定商品原图。 |
| 授权参考来源 | RSS / Atom 链接与授权条件，或 Pinterest 画板数字 ID、拥有读取权限的令牌及引用条件。每日发现新条目、去重、记录来源并提出候选方法，供管理员核实。 |
| 本地活动 | 在「本地活动」核对主办方来源、城市和日期。系统根据经营地区和本周日期选取主题。 |

未配置远程文案服务时，应用会检测已由设备所有者启用的 macOS Foundation Models CLI。两者都不可用时，一键创作在文案环节提示「请在模型平台启用文字模型后重试文案」，任务不会扣积分。对接的服务按其自身条款计费。

运营人员也可使用环境变量配置。环境变量优先于界面设置。

在「运营管理 → 模型平台」填写平台的 **Base URL**（例如 `https://api.example.com/v1`）和 **API Key**，点击「同步最新模型」，从下拉框选择模型后即可「测试连接」。点击「保存并启用」将所选模型用于当前用途。本机服务可留空密钥，已保存的密钥可在原地址沿用。

模型按文字类、图片类、图片审核类、视频生成类展示。每类均可选择多个已添加的平台，并独立选择该平台的模型。「添加平台」可保存不同地址或账号的平台，支持自定义名称。同一平台在其他分类中复用已保存的 Base URL、API Key 和同步目录，图片类另有图片编辑入口。「高级设置与用量」可切换备用连接、本地处理或原有部署配置，并查看账单和用量。

内测目录按平台和用途显示全部候选。正式路由要求核实 2026 年起的实际发布日期、官方依据、系列门槛及实测记录。平台明确提供的发布日期作为展示信息，普通 `created` 时间不视为发布日期。选择模型后可查看平台提供的发布日期和来源链接。Atlas 公开目录中的价格随同步更新，文字模型显示每百万 token 的输入与输出价格，图片和视频显示平台提供的单价与单位；单位缺失时标注待核实，未返回价格时显示“平台未提供价格”。公开目录价格供比较，实际费用取决于账号及请求参数。

- **同步最新模型**使用当前地址与密钥读取平台模型目录，按能力过滤并记录同步时间。更换地址或密钥后需重新同步。[方舟 Models API](https://docs.volcengine.com/docs/ark/models-api?lang=zh) · [百炼模型列表 API](https://help.aliyun.com/zh/model-studio/list-models)
- **测试连接**：使用当前表单执行实际请求，不切换正式路由。文案检查结构化响应，视觉审核识别随机色卡，图片实际生成并解码，视频提交异步任务、查询、下载并解码 216 帧。图片和视频可在测试结果内预览；显示耗时和错误原因。测试会产生平台用量。视频查询超时后在同一测试结果上重试会复用原任务。

云端视频接入方舟异步任务、Atlas Cloud 文生视频和百炼万相异步文生视频。连接使用对应平台的提交与查询协议。各模型返回的素材在本地按确认时长合成，重试复用已有任务。百炼可使用所属工作空间的 Base URL。[Atlas 视频协议](https://www.atlascloud.ai/docs/models/video) · [百炼视频协议](https://www.alibabacloud.com/help/en/model-studio/text-to-video-api-reference)动态视频提供成品和含净画面、字幕、音轨的剪辑包；静态 HyperFrames 源工程不适用于动态背景，不提供该项导出。今日请求统计按平台、模型和用途展示请求、耗时及平台返回的 token 用量；视频统计为任务提交响应，并非成品质量结论。

方舟与百炼按所填地址和密钥同步模型。视觉审核所选模型须支持同一请求内的多张 Base64 图片。各平台的 Chat Completions 文档列出适配的模型和输入格式。[Atlas Cloud](https://www.atlascloud.ai/docs/llm-protocols) · [火山方舟](https://docs.volcengine.com/docs/ark/chat-api) · [阿里云百炼](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope) · [DeepSeek](https://api-docs.deepseek.com/api/create-chat-completion/)

设置 `TRUPIC_DAILY_TEXT_CALLS`、`TRUPIC_DAILY_IMAGE_CALLS`、`TRUPIC_DAILY_VIDEO_CALLS`、`TRUPIC_DAILY_EDIT_CALLS` 和 `TRUPIC_DAILY_VISION_CALLS` 可分别限制整个服务在 UTC 自然日内发出的模型与图像请求次数。使用非负整数，留空表示不限次数，0 表示禁止该能力发起外部请求（已选云端连接会报错，可切换至本地处理）。服务在发送请求前计数，超时也占用一次。运营管理的「模型平台」显示当日模型调用记录。

## 商品保真与成品审核

网页或小程序选好商品图后，在「核对商品素材」中点选原图上的两个对角，框住必须保持清晰的商标或包装文字。明确要求保真的海报或短片会在预览前检查这片区域。商家确认原图中的内容完整后再生成。

每份新海报都会检查导出的 PNG。短片还会按确认时长逐帧解码，与对应分镜比对，并对各个镜头抽取首、中、尾帧，检查商品区域、文字边界和图文对比度。系统同时核对字幕、交易条件、时长、帧率与音轨。可修复的排版、裁切、偏色或编码问题触发一次重制，使用已确认文案、完整原图和分区排版。只有复检通过的版本才交付并结算。查看作品的「检查记录」，或在「运营管理 → 成品视觉审核」查看初检、重制与拦截记录。

默认在本机检查像素和排版。要评审商品遮挡、图文语义及三镜头推进，可在「模型平台 → 商品与成品视觉审核」填写支持图片输入的 Chat Completions 地址、密钥和模型，并选为调用连接，或设置 `TRUPIC_VISION_MODEL`。启用后，预览会送审原图，交付前会送审原图、海报和短片代表帧。模型未返回有效结论时可重试。可用 `TRUPIC_DAILY_VISION_CALLS` 设置独立调用上限。产品是否与线下实物一致以商家原图和确认为依据。

### 复跑真实视觉验收

本机可通过 llama.cpp 运行 Qwen3-VL。安装含多模态支持的 `llama-server`，将 `Qwen3VL-2B-Instruct-Q4_K_M.gguf` 和 `mmproj-Qwen3VL-2B-Instruct-Q8_0.gguf` 放进 `.trupic/models/Qwen3-VL-2B-Instruct/`，再执行 `npm run vision:serve`。默认监听本机 7395 端口。本机的 Qwen3-VL-2B 逐镜读取实际商品区域，完整原图与成品另做像素比对，通过后再读取整幅海报或三镜并列图写构图观察。作品审核记录将商品结论与画面观察分别保存。[官方模型权重](https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct-GGUF)

在另一终端运行下例，替换商品照片、需求和新建的输出目录。若有保真标识选区，加上 `--region 左 上 右 下`，四个坐标均按原图宽高归一化。

```sh
TRUPIC_MODEL_URL=http://127.0.0.1:7395/v1/chat/completions \
TRUPIC_VISION_MODEL=Qwen3-VL-2B-Instruct \
.venv/bin/python scripts/verify-real-vision.py --photo /path/to/product.jpg \
  --brief '用实拍图介绍这台相机' --output /path/to/new-review
```

脚本在临时数据库中走上传、方案预览、任务、审核和下载流程。它会在首次导出时遮住海报商品，并把短片第二镜置黑。输出目录保存首次导出、复检通过的成品和两轮审核记录。使用云端接口复跑时，图片会发送至选定平台并产生实际模型调用。

## 管理与数据

首次启动会在 `.trupic/admin.key` 生成本机专用管理密钥。打开左侧「运营管理」并使用该密钥登录。登录后可在「运营管理 → 管理密码」用当前密钥设置自己的密码，无需重启。新密码以哈希保存在数据库，修改后初始密钥和其他管理会话失效。它与商家账号密码分别管理。

也可在启动前设置 `TRUPIC_ADMIN_KEY` 来指定管理密码。环境配置优先时页面会说明来源，并禁止通过页面覆盖；需要修改启动配置后重启。

- 案例库支持优秀、反面及方法分类。入库需记录授权条件和拆解，反面案例需注明具体问题。
- 策略版本可关联已审核的方法。固定测试检查典型业务、版本差异和真实性门槛，记录候选与初始策略结果。支持按商家稳定分组的 10% 灰度、全量启用和回退。
- 运营可抽查作品、查看历史和审核标签，填写来源、统计区间及真实展示、点击、咨询、到店数据。策略页汇总已录入的实际反馈，供版本评估参考。
- 在「技能库」编辑已接入方法的分阶段指导，填写原因并运行固定测试。可对通过的修订进行 10% 稳定分组灰度、全量启用或回退。已签发的创作方案与历史版本保留当时的指导和版本号。
- 每个商家有独立作品、素材、档案和积分账本。每周准备差异化主题，助理会按商家设置在对话内展示。管理员操作留有审计记录。
- 数据目录默认是 `.trupic/`，可通过 `TRUPIC_DATA` 更改。备份应包含 SQLite 数据库、作品、素材、商家字体和会话密钥。服务默认只监听本机回环地址。

### 营销日历与公开热点

在「运营管理 → 营销日历」可同步、暂停和登记主办方来源。服务每日更新，失败一小时后重试。超过 48 小时未核验的自动来源退出推荐。新快照会撤回取消、下架或改期的旧事件，历史作品保留当时的依据。手工核实录入的活动仍可使用。

- 香港假期采用 1823 公布的数据，仅匹配香港经营地区。服务优先按官方域名连接。如果已配置的 HTTP 代理在握手中断开，服务通过 Google Public DNS 的 HTTPS 接口查询该域名的公网 IPv4 地址，再经原代理连接；TLS 证书校验和 HTTP 请求仍使用官方域名。[1823 假期数据说明](https://data.gov.hk/sc-data/dataset/hk-dpo-statistic-cal)
- 本地活动来源支持完整的 Schema.org Event JSON 列表、ItemList 或 @graph。每项提供名称、起始日期及 location.address.addressLocality，主办方可提供结束日期、详情网址和 eventStatus。只采纳来源登记地区内仍有效的事件。
- 公开热点支持官方 RSS 或 Atom。登记来源时填写适用行业，系统取同一发布方的详情链接和近七日的公告日期。内置 Apple 开发者中文订阅匹配应用开发或编程培训等档案。公告日期在推荐中明确标为发布日期。[Apple 开发者动态](https://developer.apple.com/cn/news/)

### 模型预算与账单核对

部署方可使用 `TRUPIC_DAILY_BUDGET_CNY` 设置每日人民币预留上限，并用 `TRUPIC_TEXT_RESERVE_CNY`、`TRUPIC_IMAGE_RESERVE_CNY`、`TRUPIC_VIDEO_RESERVE_CNY`、`TRUPIC_VISION_RESERVE_CNY` 配置各能力每次请求的估算金额，支持六位小数。请按已开通模型、允许的最大输出及供应商价格配置。服务在发送请求前原子检查用量与金额上限。超时请求保留预留额。未设每日金额上限时，原有的调用次数控制继续生效。

「模型平台 → 模型预算与账单」分别展示预留额与已核对的供应商账单。按 UTC 日期、平台、模型、用途和币种录入当日合计及凭证来源，再次核对同一条记录会更新金额。商家积分继续按确认的交付项结算。

商业文案使用项目内的 [hiccai-wenan v4.2.0](.agents/skills/hiccai-wenan/SKILL.md)，固定到[上游提交 643480d](https://github.com/laixi969-coder/hiccai-wenan/tree/643480ded24d513123ec95647ca2aad0f25a767b)。发布时随项目保留整个 Skill 目录。模型写稿和独立复核都会读取原文及当前媒介的参考章节。海报按商家选中的复核稿制作。纯文案等离线任务支持本地实现的促销直述、交易条件保留和按需省略行动号召等规则。作品的「检查记录 → 文案 Skill」记录该版本实际使用的路径。

### 商业海报与短片

在「版式与字体」可选「商品主视觉」「单双色孔版」或「品牌 IP 场景」。孔版示例可输入“蓝墨单色印刷”，或“蓝墨橙墨双色印刷”。前者导出一个墨层，后者导出两个。品牌 IP 需要上传角色参考图。商品主视觉、孔版和 IP 海报在使用对应分层渲染时，可从作品页下载 SVG，编辑文字、替换底图。已分离的商品有独立图层，完整摄影原图以整张照片保存。SVG 使用字体名称，异机编辑需安装对应字体。

新增「食欲定格」「留白光影」「照片编排」。例如「日式美食，居酒屋暗调」「留白光影，突出瓶身反光」「照片编排，保留完整骑行原片」可直接写进需求，也可在网页手选。「灵感广场 → 海报版式」提供对应实排样张。PNG 完成原图和交易信息检查后交付，SVG 保留照片、图框、底色和排字图层。[35 张样本与 Pinterest 拆解](.agents/skills/trupic-commercial-poster/references/poster-reference-review.md)

首稿会把商家的推广目的与商品图的画幅、明暗、细节密度和留白一起考虑，从全图（满版摄影）、留白光影、双色孔版中自动选一种；促销优先排清优惠与条件。选中的排法与理由随作品保存。商家也可以明确指定取景框，或在「照片编排」作品的专业建议里手动切换。满版稿按实际字体和文案长度安排原片，横幅在照片侧边排字，有优惠时把数字和有效期排在一起。改稿复用原片与已确认文案，保留原版本，可继续下载可编辑 SVG。[排版方法](.agents/skills/layout-grid/SKILL.md)

短片将摄影画面与字幕分开渲染，按开场、细节与收束调整取景。交付前解码导出的 MP4，再检查各镜实际商品及所选标识。运营后台可分别选择文本和视觉平台，查看调用次数、耗时、错误及供应商返回的 token 用量。供应商报价及真实账单另行核对。设计来源及具体取舍见[商业海报视觉研究](.agents/skills/trupic-commercial-poster/references/visual-study.md)。

商品主视觉会结合已确认资料与实物剪影选择构图。摄影器材可用取景投影，原色机身与其型号文字叠放。食材海报可从原图取色，按食材名称和主体轮廓安排前后景。短片作品页的「下载剪辑素材包」包含净画面、逐镜透明字层、可修改字幕 SRT、音轨、CMX 剪点表和镜头说明。三个镜头分别借鉴分层视差、细节慢推和片尾定版。[video-shotcraft 镜头库](https://github.com/Vincentwei1021/video-shotcraft/tree/59f3e9b9e936ff2bce0e18446226d770a3f2f61f/references/shots)

#### 用 Open Design 继续剪辑

新短片优先由 Open Design 同款的 HyperFrames 渲染。`npm ci` 会安装可选的 HyperFrames 运行时。准备 Chrome 时可执行 `npx hyperframes browser ensure`。默认 `TRUPIC_VIDEO_RENDERER=auto`，运行时不可用或渲染失败时改用本地 FFmpeg，仍可交付剪辑工程。可设为 `hyperframes` 要求使用该引擎，或设为 `ffmpeg` 直接使用 FFmpeg。作品的「检查记录」显示实际引擎。MP4 继续走商品保真、文字、音轨和逐帧审核。[Open Design 的 HyperFrames 视频工作流](https://github.com/nexu-io/open-design/tree/e033aad1d15a9d4084316e5223f2c6597fd32619/design-templates/hyperframes)

在网页短片作品页点击「下载 Open Design 剪辑工程」。解压后，在 Open Design 桌面端打开解压目录作为项目，从 `index.html` 进入。镜头时间、画面图层、字幕图层和音轨可单独调整，工程附带源 MP4、逐镜字幕 SVG 和 SRT。成片默认使用已审核的 PNG 字层。修改 SVG 后可将对应字幕轨指向 SVG，预览与导出时需安装相应字体。也可以在解压目录运行 `npx hyperframes@0.9.40 preview`，用 HyperFrames 时间线继续编辑。

### 用标注成品评测商品保真

运行 `.venv/bin/python scripts/evaluate-fidelity.py /path/to/manifest.json`。输入为 JSON 数组，每项包含行业 `industry`、原图路径 `photo`、成品图片路径 `export`、该商品在成品上的像素坐标 `box: [左,上,右,下]` 和人工标签 `expected`（`pass` 或 `block`）。可提供相对原图归一化的标识选区 `region` 和单独的主体蒙版 `mask`。图片路径相对于清单文件。报告使用交付时相同的局部像素比对，按行业报告正常、异常样本数以及误报和漏报率。只有正常或只有异常样本时，对应缺少分母的指标显示 null。
